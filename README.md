# BoxMover
Minecrft 1.14-1.20.4 datapack

本数据包是为了方便玩家搬运「容器」而设计，「容器」指的是原版 MC 中的以下 **[方块实体](https://zh.minecraft.wiki/w/方块实体)**：

箱子、陷阱箱、木桶、熔炉、高炉、烟熏炉、漏斗、发射器、投掷器、酿造台、雕纹书架和饰纹陶罐。

注意事项：

1. 搬运容器时，对应容器的[战利品表](https://zh.minecraft.wiki/w/战利品表)会被抹除（正确做法是先打开宝箱）。

2. 请不要将本数据包与含『容器带锁』功能的组件一起使用。

3. 雕纹书架和饰纹陶罐分别于 1.20 与 1.20.3 出现。

==========

This datapack is designed for players moving their "containers", which means the following **[Block Entities](https://minecraft.wiki/w/Block_entity)**:

Chest, trapped chest, barrel, furnace, blast furnace, smoker, hopper, dispenser, dropper, brewing stand, chiseled bookshelf and decorated pot.

Tips: 

1. When moving a "container", its [Loot Table](https://minecraft.wiki/w/Loot_table) will be removed (so you need to open the treasure boxes at the first time).

2. DON'T use this datapack with other mods/plugins/datapacks that with "Locking Containers" functions.

3. The chiseled bookshelf and decorated pot are new container blocks since MC 1.20 and 1.20.3.
